# KABA BOY Compta

Appli personnelle de KABA BOY TV pour faire les factures et les devis, suivre les dépenses et préparer la déclaration d'impôts en Allemagne (Anlage EÜR, Kleinunternehmer § 19 UStG).

- Appli : https://yamar100.github.io/kaba-boy-compta/
- À installer sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».

Ce dépôt ne contient que le code de l'appli. Les données (factures, dépenses, justificatifs) sont dans un dépôt **privé** séparé, lu avec un jeton d'accès qui reste sur le téléphone.
